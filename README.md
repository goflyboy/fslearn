# fslearn · 财经知识学习库

> Fibo 的财经知识学习知识库。服务于"多维数据库执行引擎（跨国企业财经数据管理）"任务的财经知识补课。
> 用 **Obsidian** 打开本目录即可作为 Vault 使用（已附 `.obsidian` 基础配置）。

## 目录结构 / Structure

```
fslearn/
├── 00-学习地图/                  # 总计划、Gap 分析、阶段路线（导航层）
│   └── 财经知识学习计划.md
├── 01-参考资料/                  # 【只读】下载/翻译/整理的原始资料
│   └── 阶段1-财务报表分析/
│       ├── 杜邦分析体系-中英对照.md   ← 逐段中英对照 + 原文配图
│       ├── 书目卡-*.md                ← 3 本书（元数据+封面+正版链接）
│       ├── 课程卡-*.md                ← 2 门 MOOC
│       ├── assets/                    ← 4 张图片（杜邦2图 + 封面2张）
│       └── README.md
├── 02-学习沉淀/                  # 【你的输出】笔记、作答、数据字典
│   ├── 阶段0-财经全景/
│   ├── 阶段1-财务报表分析/
│   │   └── 实战作答-模板.md
│   └── 数据字典/
│       └── 财务数据字典-模板.md
├── 99-项目元信息/                # 版权边界、来源说明
│   └── 资料来源与版权说明.md
└── .obsidian/                    # Obsidian 配置
```

## 设计原则 / Principles

1. **参考资料 ≠ 学习沉淀**：`01-参考资料/` 是只读原始材料（含翻译），`02-学习沉淀/` 是你自己写的笔记与作答。两者物理隔离，避免混淆"资料说的"和"我理解的"。
2. **按阶段组织**：阶段 0-5 与学习计划一一对应，后续新增阶段直接建同级目录。
3. **版权合规**：商业书全文、MOOC 视频不入库，只放元数据/封面/正版链接；公开文章可下载转 MD。详见 `99-项目元信息/资料来源与版权说明.md`。
4. **中英对照学英文**：阶段一中文材料做"中译英"逐段对照（AI 辅助），并建立财经术语表，衔接后续 IFRS 英文准则阅读。

## 使用方式 / Usage

- **Obsidian**：打开 Obsidian → Open folder as vault → 选择 `fslearn`。用 `[[双向链接]]` 把沉淀笔记连到参考资料。
- **Git**：本仓库同时是 GitHub 仓库 `goflyboy/fslearn`，外网可 `git clone https://github.com/goflyboy/fslearn.git` 下载。
