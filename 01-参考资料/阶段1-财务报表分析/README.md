## 关于"中英对照" / About bilingual layout

阶段一 6 项材料中 5 项为纯中文，唯一英文相关材料是 BAV 原版书。因此对中文材料的"中英对照"实为**中译英**（AI 辅助），用于建立财经英文词汇、衔接后续 IFRS 英文准则阅读。英文原文的正确读法见书目卡中的英文原版获取方式。
